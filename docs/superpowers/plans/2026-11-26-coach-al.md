# Coach & AL features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Roles (AL/Coach), a Coach review page of all eCamp blocks, Termine deadlines relative to the camp, receipt upload with a booking, and an AL status overview on `/lager`.

**Architecture:** Next.js 16 App Router, server components read Drive (as the user) and eCamp (one technical guest account) through the existing loaders and the in-process `cached()` helper. Pure logic in `lib/*.ts` with `node:test` tests next to it; I/O in `lib/data/`. One PR per task, squash-merged.

**Tech Stack:** Next.js 16, React 19, TypeScript 7, zod 4, exceljs, node:test.

**Spec:** `docs/superpowers/specs/2026-11-26-coach-review-design.md`

## Global Constraints

- CLAUDE.md: screens in `app/`, one component per file in `components/`, I/O in `lib/data/`, pure helpers in `lib/`, no file over 300 lines, tests next to the file, local imports in test-reachable files use `.ts`.
- eCamp text is user HTML: never `dangerouslySetInnerHTML`; render plain text only.
- Roles never widen Drive access; Drive still decides who sees which file.
- UI copy in German (Swiss: "ss", no "ß").
- Verify each task: `docker run --rm -v "$PWD":/app -v pfadi-nm:/app/node_modules -v /etc/ssl/certs/ca-certificates.crt:/ca.crt:ro -e NODE_EXTRA_CA_CERTS=/ca.crt -w /app node:26-alpine sh -c "npm ci && npx tsc --noEmit && npm test && npx next build; rm -rf .next"` → tsc silent, all tests pass, build lists the route.
- Commits/PR titles: `type(scope): summary`, lowercase, imperative.

## Review Focus

- eCamp HTML with `<script>`, entities (`&amp;`, `&nbsp;`) and nested lists → plain text, entities decoded, no tags left (Task 2 test `htmlToText`).
- Camp with no eCamp connected or no dates → Coach page and relative Termine degrade to a notice / "ohne Datum", never a crash (Tasks 2, 3 tests).
- Blocks crossing midnight or spanning two parts of the day → counted in the day they start, every part of the day they touch counts (Task 2 test `checkDays`).
- `roles` missing from `camps.json` (all existing installs) → config still parses, nobody has a role (Task 1 test).
- Receipt upload succeeds but booking fails → error shown, the file stays in Drive, form keeps its values (Task 4, manual check in PR).
